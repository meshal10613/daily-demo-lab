# Markdown Table Formatter

A fast CLI utility and Python library to parse, column-align, pad, and format Markdown tables.

## Features
- Automatic column width calculation.
- Respects and preserves left, right, and center alignments (`:---`, `---:`, `:---:`).
- Zero external dependencies.

## Usage
```bash
python run.py --demo
```

## Tests
```bash
python -m unittest discover -s tests -p 'test_*.py'
```
